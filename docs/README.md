## 기록 원칙

- 실제 결과 파일로 확인된 수치만 사용합니다.
- 기대 결과와 실제 결과를 구분합니다.
- 문제는 재현 조건, 원인, 조치, 재테스트 순서로 기록합니다.
- 아동 개인정보와 관리자 자료는 공개 증빙에 포함하지 않습니다.
