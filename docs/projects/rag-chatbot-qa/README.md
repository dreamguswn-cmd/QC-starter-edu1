# RAG 챗봇 자동평가 및 답변 개선

## 프로젝트 정보

- 유형: 개인 프로젝트
- 개인 기여: 평가 기준 설계, 자동평가, 원인 분석, 개선 로직, 재테스트, 결과 보고 전 과정
- 기술: RAG, LLM-as-a-Judge, Two-Stage Evaluation, Correction Agent

## 문제 정의

근거를 사용하지 않거나 출처가 누락된 RAG 응답을 동일한 기준으로 식별하고 개선 결과를 다시 검증해야 했습니다.

## 테스트와 개선

1. 정확성·근거성·관련성·표현 품질 기준을 정의했습니다.
2. 응답 5건을 자동평가하고 감점 사유를 JSON으로 기록했습니다.
3. 평가 JSON을 Correction Agent 입력으로 전달했습니다.
4. 개선된 답변을 같은 평가 기준으로 재검증했습니다.

## 결과

- 자동 테스트: 5건
- 평균 점수: 4.20/5
- 검색 → 생성 → 평가 → 수정 → 보고의 9단계 품질검증 흐름 완성
