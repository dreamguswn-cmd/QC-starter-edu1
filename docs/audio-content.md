# AI 음악 콘텐츠

## 권리 및 제작 정보

- 음악 기획 및 학습 노래 가사: 유현주
- 생성 도구: Suno AI
- 이용 조건: Suno 유료 요금제 이용 기간에 생성
- 사용 범위: 유현주 QA 포트폴리오의 배경음악 및 학습 콘텐츠
- 원본 생성 기록과 구독·결제 내역은 권리 확인 자료로 별도 보관합니다.
- 음악 파일의 별도 복제, 재배포 또는 제3자 콘텐츠 사용은 허용하지 않습니다.

생성형 AI 결과물의 저작권 인정 범위는 국가별로 다를 수 있습니다. 위 표시는 제작 과정과 서비스 이용 권한을 투명하게 설명하기 위한 것입니다.

포트폴리오의 핵심 QA 프로젝트를 방해하지 않는 범위에서 생성형 AI 활용과 학습 콘텐츠 기획 경험을 보여주기 위해 구성했습니다.

## Quality in Motion

- 역할: 포트폴리오 메인 배경음악
- 형식: 보컬 없는 테크 앰비언트
- 재생: 방문자가 직접 선택하며 자동재생하지 않음
- 사이트 음량: 16%
- 편집: 마지막 무음 제거, 시작과 끝 교차 연결, 반복 재생용 음량 조정
- 파일: [`public/audio/quality-in-motion-bgm.mp3`](../public/audio/quality-in-motion-bgm.mp3)

## QA 용어 학습 노래

- 역할: QA 전문용어의 의미를 쉽게 전달하는 부가 학습 콘텐츠
- 내용: QA, 테스트 케이스, 자동화, RAG, 모니터링, AWS 장애복구 등
- 재생: 페이지 하단에서 방문자가 직접 선택하며 한 번 재생
- 배치: 대표 프로젝트와 직접 만든 웹사이트보다 아래에 배치
- 파일: [`public/audio/qa-terms-learning-song.mp3`](../public/audio/qa-terms-learning-song.mp3)

## 재생 원칙

1. 두 음악 모두 자동으로 재생하지 않습니다.
2. 메인 BGM과 학습 노래는 동시에 재생되지 않습니다.
3. 학습 노래를 재생하면 메인 BGM이 일시정지됩니다.
4. 메인 BGM을 다시 재생하면 학습 노래가 일시정지됩니다.
5. 음악은 QA 경력과 프로젝트 증빙보다 낮은 우선순위의 부가 콘텐츠로 표시합니다.
