# 품질 발견사항과 개선 기록

## QF-001 · 웹 서비스 중지 장애

| 항목 | 내용 |
|---|---|
| 문제 | Apache 중지 시 웹페이지 접속 실패 |
| 재현 조건 | 정상 접속 확인 후 Apache 서비스를 의도적으로 중지 |
| 실제 결과 | 브라우저에서 서비스 접속 실패 |
| 원인 | Apache 서비스가 중지 상태임을 확인 |
| 조치 | Apache 서비스를 재시작 |
| 재테스트 | 동일 URL에 다시 접속하여 정상 화면 확인 |
| 결과 | 장애 복구 평가 100점 |

## QF-002 · AI 답변의 근거 사용 품질

| 항목 | 내용 |
|---|---|
| 문제 | RAG 답변에서 근거 미사용 또는 출처 누락 가능성 |
| 탐지 방법 | 루브릭 평가와 감점 규칙을 분리한 Two-Stage Evaluation |
| 조치 | 평가 JSON과 감점 사유를 Correction Agent 입력으로 재사용 |
| 재검증 | 개선 답변을 동일한 평가 흐름으로 다시 검토 |
| 결과 | 검색→생성→평가→수정→보고의 품질 개선 흐름 구축 |
