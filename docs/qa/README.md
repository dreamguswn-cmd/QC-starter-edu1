# QA 목표와 범위

## 목표

AI 서비스와 클라우드 운영 환경의 기능, 응답 품질, 성능, 모니터링, 장애 복구를 검증하고 결과를 재현 가능한 증빙으로 남기는 것을 목표로 합니다.

## 검증 범위

| 영역 | 주요 검증 내용 | 도구 및 환경 |
|---|---|---|
| 기능 | 정상 입력, 오류 처리, 회귀 동작 | pytest, FastAPI |
| AI 품질 | 정확성, 관련성, 근거 사용, 표현성 | RAG, LLM-as-a-Judge |
| 성능 | 응답 시간, 오류율, 부하 상태 | k6 |
| 모니터링 | 서비스 상태와 운영 지표 관찰 | Prometheus, Grafana |
| 클라우드 운영 | EC2, 웹 서비스, S3 보안 | AWS EC2, S3, CloudTrail |
| 장애 복구 | 장애 재현, 원인 확인, 복구 재검증 | Apache, AWS |

## 공통 QA 흐름

1. 검증 대상과 품질 기준을 정의합니다.
2. 테스트 조건과 기대 결과를 기록합니다.
3. 동일한 조건으로 실행하고 실제 결과를 수집합니다.
4. 차이가 발생하면 재현 조건과 원인을 분석합니다.
5. 개선 후 같은 조건으로 다시 테스트합니다.
6. 결과와 증빙을 보고서와 저장소에 남깁니다.
