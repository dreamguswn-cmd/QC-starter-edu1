# 시스템 구조

## 구성

```text
방문자
  └─ GitHub Pages 공개 포트폴리오
       ├─ QA 성과·프로젝트·증빙
       ├─ 이력서와 공개 결과물
       └─ 직접 만든 웹사이트

관리자
  └─ Supabase Auth 로그인
       ├─ 포트폴리오 콘텐츠 저장 (site_settings)
       ├─ 프로필·이력서 저장 (portfolio-public)
       └─ 초등돌봄 자료 저장 (care-private)
```

## 공개와 비공개 경계

| 영역 | 접근 |
|---|---|
| 포트폴리오 화면과 공개 증빙 | 누구나 열람 가능 |
| 포트폴리오 콘텐츠 수정 | 등록된 관리자만 가능 |
| 초등돌봄 자료 업로드 | 등록된 관리자만 가능 |
| 초등돌봄 파일 목록과 열람 | 인증된 보호 화면에서만 가능 |

## 배포

`main` 브랜치 변경 시 GitHub Actions가 Vite 앱을 빌드하고 GitHub Pages에 배포합니다.
