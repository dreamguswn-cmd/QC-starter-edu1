PROJECT 01 · EXPLORATORY DATA ANALYSIS

Python 탐색적 데이터 분석(EDA)

고객 데이터의 구조·분포·결측값을 확인하고 IQR과 Z-score로 이상 고객을 탐지하여 멤버십, 만족도, 이탈 여부까지 함께 분석했습니다.

LanguagePython
EnvironmentJupyterLab
Librariespandas · matplotlib
Datasetcustomer.csv

데이터 이해

head, tail, shape, columns, info로 행·열 수, 자료형, 결측값과 메모리 사용량을 확인했습니다.

품질 점검

age 20건, monthly_spend 15건, satisfaction_score 10건의 결측값을 탐지하고 삭제·평균·중앙값 대체를 비교했습니다.

분포 분석

히스토그램과 Box Plot으로 나이와 월 지출액의 분포, 왜도, 중앙값, 사분위수와 이상값을 확인했습니다.

이상 고객 분석

IQR 및 |Z| > 3 기준으로 이상값을 찾고 Customer ID, Membership, Satisfaction Score, Churn을 함께 검토했습니다.

핵심 분석 코드

df = pd.read_csv("customer.csv")
df.info()
df.describe()
df.isnull().sum()

q1 = df["age"].quantile(0.25)
q3 = df["age"].quantile(0.75)
iqr = q3 - q1
outliers = df[(df["age"] < q1 - 1.5 * iqr) |
              (df["age"] > q3 + 1.5 * iqr)]

분석 결과
나이에서는 96·103·120세, 월 지출액에서는 582.5·545·507.5·470·432.5 등의 이상값을 확인했습니다. 단순 제거가 아니라 고객 특성과 이탈 여부를 함께 살펴 데이터의 의미를 보존하는 분석 관점을 익혔습니다.

PROJECT 02 · DATA MANIPULATION

R 기초 및 데이터 조작

R의 자료형과 자료구조부터 Data Frame 생성, 파생변수 계산, 조건부 고객등급 생성, CSV 저장과 행 결합까지 실습했습니다.

LanguageR
EnvironmentRStudio
Packagedplyr
FocusData Manipulation

기초 문법

사칙연산, 변수 생성, as.numeric·as.character 자료형 변환과 class·typeof 계열 함수를 실습했습니다.

자료구조

Vector, Array, List, Factor, Data Frame의 구조와 용도를 비교했습니다.

파생변수

quantity × price로 총 구매금액 amount를 만들고, ifelse로 10만원 이상 고객을 ‘우수’ 등급으로 분류했습니다.

저장·결합

write.csv로 결과를 저장하고 rbind로 동일 구조의 판매 데이터를 행 단위로 결합했습니다.

핵심 데이터 조작 코드

sales$amount <- sales$quantity * sales$price
sales$grade <- ifelse(
  sales$amount >= 100000,
  "우수",
  "일반"
)

combined_sales <- rbind(sales, new_sales)
write.csv(combined_sales, "sales_result.csv", row.names = FALSE)

프로젝트 결과
R의 핵심 자료구조를 이해하고, 분석 목적에 맞는 파생변수와 범주형 등급을 생성했습니다. 생성한 데이터를 CSV로 저장하고 추가 데이터를 결합하는 기본 데이터 처리 흐름을 완성했습니다.
